Avancerade krav:
1. Om man skriver siffor, specialtecken, flera bokstäver, mellanslag eller ENTER så kommer de inte räknas som en gissning eller visas som en gissad bokstav.
2. Om man gissar en bokstav som finns i ordet mer än en gång kommer alla visas.
3. Om man vinner får man lika många poäng som det finns gissningar kvar.
4. Om man vinner eller förlorar kommer spelet fråga om man vill spela igen. Om man trycker ENTER kommer en ny omgång startas, men om man skriver något annat kommer spelet avslutas.
5. För varje felgissning kommer det ritas ut en ASCII-gubbe som blir mer komplett varje gång.
